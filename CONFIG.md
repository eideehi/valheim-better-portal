# Configurations

## [ #1 General ] / [general]

### Modifier Key / [ModifierKey]

The key to hold when interacting with a portal to set its destination tag.

- Default value: LeftShift
- `None` is not allowed. If this value is set to `None`, Better Portal resets it to the default value.
- Left and right variants of Shift, Control, and Alt are treated as pairs. For example, if `LeftShift` is configured, either Shift key can be used.
