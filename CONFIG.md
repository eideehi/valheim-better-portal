# Configurations

## [ #1 General ] / [general]

### Modifier Key / [ModifierKey]

The key to hold when interacting with a portal to set its destination tag.

- Default value: LeftShift
- `None` is not allowed. If this value is set to `None`, Better Portal resets it to the default value.
- Left and right variants of Shift, Control, and Alt are treated as pairs. For example, if `LeftShift` is configured, either Shift key can be used.

## [ Settings screen ] / [mod_utils]

### Show on the Settings screen / [show_on_settings_screen]

Shows this mod on the Mods tab of the game's Settings screen. When no mod is shown there, the tab is not added. A change applies the next time the Settings screen opens. After turning this off, turn it back on in ConfigurationManager or in this mod's config file.

- Default value: true
- This option is not shown in the Better Portal panel of the Settings screen.
